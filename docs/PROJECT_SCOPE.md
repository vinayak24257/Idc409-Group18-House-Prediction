# Project Scope

## Final project
House price prediction using the Ames Housing dataset.

## Target
SalePrice, measured in US dollars.

## Historical work
The earlier Indian housing data-cleaning and EDA work belongs to
the project's development history. It must not be presented as
EDA for the final Ames model.

## Modelling
Model selection must use appropriate validation, with preprocessing
fitted only on training data. After model selection, the approved
pipeline may be retrained on all labelled training records.

## Application
The prediction application must use the approved model and its
documented input schema.

## Limitations
The model estimates prices in the context of the historical Ames,
Iowa housing dataset. It must not be represented as a model for
current market prices or Indian properties.
